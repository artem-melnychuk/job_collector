# Job Collector

Python-пайплайн: собирает вакансии из нескольких источников, удаляет дубли, классифицирует их, показывает, какие навыки и сертификаты рынок реально требует, и готовит материалы для откликов с обязательным одобрением человеком. Сделан под роли аналитика данных, бизнес- и продуктового аналитика с уклоном в крипто и финтех.

English version: [README.md](README.md). Рабочие заметки для разработчиков и ИИ-ассистентов: [CLAUDE.md](CLAUDE.md).

> Это публичная витринная копия. Реальный накопительный датасет и личные заметки хранятся в приватном репозитории, здесь `data/processed/` содержит пустой шаблон с той же схемой.

## Что делает

1. **Собирает** вакансии из источников в единую схему `JobRecord`.
2. **Удаляет дубли и объединяет**: стабильный ID (`источник + нормализованный URL`) делает повторные запуски безопасными; поля ручной проверки сохраняются при каждом перезапуске.
3. **Фильтрует при сборе**: требование французского или немецкого, on-site вакансии в исключённых странах, скам-объявления, минимальный опыт.
4. **Анализирует** по прозрачным правилам: семейство роли, уровень, лет опыта, навыки с разделением на обязательные и желательные.
5. **Строит отчёты**: какие навыки повторяются в подходящих вакансиях, но отсутствуют у кандидата, с долей всех вакансий рынка и признаком «просят ли сертификат». Действие (`learn`, `optional`, `low priority`, `verify first`) считается по порогам, а не по зашитым названиям инструментов.
6. **Помогает с откликами (по желанию, платные вызовы LLM API)**: оценка соответствия, черновик записки и пунктов CV, отдельный вызов-ревьюер, сборка PDF с проверкой текстового слоя по ключевым словам вакансии, лист статусов. Ничего не отправляется автоматически.

## Источники

| Источник | Как | Примечание |
|---|---|---|
| LinkedIn | Playwright, сначала JSON-LD, затем CSS | Authwall и смена вёрстки ожидаемы |
| Карьерные страницы компаний | Публичные API Greenhouse и Lever | Список в `config/companies.yaml` |
| Djinni | RSS | Украинский IT-борд, свой словарь категорий |
| RemoteOK | JSON API | Только удалёнка, фильтр по заголовку локально |
| We Work Remotely | RSS | Только удалёнка, небольшое скользящее окно |
| Welcome to the Jungle | Playwright | Только явно (`--source wttj`) |
| Work.ua, Robota.ua | Playwright | Реализованы, но блокируются анти-бот защитой; только явно |

## Установка и запуск

Из корня проекта:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt

# проверить конфигурацию без запуска коллекторов
.venv\Scripts\python.exe -B scripts\collector.py --dry-run

# собрать вакансии из всех источников по умолчанию
.venv\Scripts\python.exe -B scripts\collector.py --source all --limit 50

# классификация и извлечение навыков
.venv\Scripts\python.exe -B scripts\analyzer.py

# что учить: пробелы навыков + спрос рынка + рекомендации
.venv\Scripts\python.exe -B scripts\skills_gap_report.py

# как часто встречаются инструменты и сертификаты
.venv\Scripts\python.exe -B scripts\certification_analysis.py

# перепроверить, открыты ли сохранённые вакансии
.venv\Scripts\python.exe -B scripts\collector.py --check-availability --check-limit 500 --headless

# тесты
.venv\Scripts\python.exe -B -m unittest discover -s tests
```

Один запрос: `--source company_careers --query "Trading Analyst" --limit 20 --headless`.

## Конвейер откликов

Читает мастер-CV из `CV/` (не в репозитории) и требует `ANTHROPIC_API_KEY`. Каждый вызов LLM платный, поэтому шаги вынесены в отдельные скрипты с лимитом на запуск:

```powershell
.venv\Scripts\python.exe -B scripts\fit_score.py --limit 20     # оценка ещё не решённых вакансий
.venv\Scripts\python.exe -B scripts\cv_draft.py --limit 10      # черновик записки и пунктов CV
.venv\Scripts\python.exe -B scripts\cv_review.py --limit 10     # отдельный вызов-ревьюер
.venv\Scripts\python.exe -B scripts\cv_pdf.py --limit 20        # PDF и ATS-проверка (бесплатно)
.venv\Scripts\python.exe -B scripts\applications_tracker.py     # лист статусов (бесплатно)
```

Правило честности: черновик может только переформулировать то, что есть в CV; отдельный ревьюер проверяет выдумки, честность локации, релевантность и тон. Статус `sent` ставит только человек.

## Результаты

- `data/raw/` — отдельные файлы каждого запуска;
- `data/processed/crypto_jobs_clean_v1.xlsx` и `.csv` — накопительный датасет.

Листы processed XLSX: `jobs_master` (полная таблица, скрыта), `manual_review` (ручная оценка соответствия, жёлтые поля заполняются вручную), `skills_gap` и `skill_recommendations` (отчёты), `active_near_fit` (живые подходящие вакансии), `applications` (статусы откликов).

## Ограничения

- У LinkedIn и Welcome to the Jungle нет стабильного публичного API, смена вёрстки ломает селекторы. Публичная страница WTTJ может не применять переданный запрос.
- Извлечение навыков rule-based: короткие токены (`R`) и общие слова (`ML`) дают ложные срабатывания, отчёт помечает такие навыки, а не доверяет им.
- Счётчики рынка описывают собранную выборку (под один поисковый профиль), а не весь рынок.
- Часть проекта разработана с помощью Claude Code.
